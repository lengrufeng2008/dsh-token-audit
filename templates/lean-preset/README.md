# Lean preset (generated)

Generated by `dsh-token-audit preset`. It keeps the standard toolset and changes:

- compaction trigger and retained tail
- tool-result pruning thresholds
- a cost-discipline persona

Install:

```bash
dsh plugin --profile web add ./dsh-lean-preset
```

Restart DSH, then choose **Lean** as the agent preset for a new session. Compare cost per call with:

```bash
dsh-token-audit --format json > before.json
# ... a week later ...
dsh-token-audit --format json > after.json
dsh-token-audit compare before.json after.json
```
